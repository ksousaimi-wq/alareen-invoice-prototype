# نموذج أولي — نظام التحقق من فواتير مقاولي الباطن وأرشفتها

**اتحاد العرين للمقاولات** · Al Areen Union Contracting Co.

نموذج واجهات قابل للنقر (عربي RTL) لمنصّة التحقق من فواتير مقاولي الباطن
ومطابقتها ببنود جداول الكميات المتعاقد عليها، وكشف الفواتير المكررة،
والتحقق من الالتزام الضريبي، وأرشفة المستندات.

### 🔗 العرض المباشر

**https://ksousaimi-wq.github.io/alareen-invoice-prototype/**

### ⚠️ هذا نموذج للعرض فقط

- **كل البيانات المعروضة مُختلَقة بالكامل** — لا توجد أي فواتير أو عقود أو
  أرقام ضريبية حقيقية، والأرقام الضريبية المعروضة غير مسجّلة لدى أي جهة.
- الأزرار تعمل للتنقّل والعرض فقط — **لا يُحفَظ أي شيء** ولا توجد قاعدة بيانات.
- الغرض منه مراجعة تصميم الشاشات وسير العمل قبل بدء التطوير الفعلي.

### كيفية الاستخدام

يعمل النموذج بلا إنترنت — ملف واحد مستقل بلا أي اعتماديات خارجية. يمكن فتح
الرابط أعلاه مباشرة، أو تنزيل `index.html` وفتحه بأي متصفح.

**في شاشة الدخول اختر الدور** (مدير / محاسب مراجع / مطّلع) — دور "مطّلع" يُخفي
عمداً كل أزرار التعديل، وهو ما يعكس الصلاحيات المخطط لها فعلياً.

### الفواتير التجريبية — كل نوع ملاحظة قابل للاستعراض

| الفاتورة | ما تعرضه |
|---|---|
| `INV-1041` | فاتورة نظيفة — معتمدة للدفع |
| `INV-1042` | فاتورة مكررة (تطابق تام + بصمة ملف متطابقة) |
| `INV-1055` | انحراف سعر الوحدة عن العقد (+٨٫٥٧٪) |
| `INV-1061` | تجاوز الكمية التعاقدية (٨٬٧٢٠ من أصل ٨٬٥٠٠ م³) |
| `INV-1068` | خطأ حسابي في بند + عدم تطابق المجاميع |
| `INV-2231` | رمز QR مفقود + رقم ضريبي غير مُتحقق منه |
| `INV-2245` | انجراف سعر تاريخي مقارنة بآخر فاتورة معتمدة |
| `INV-2260` | ثقة استخراج منخفضة — بانتظار المراجعة البشرية |
| `INV-3301` | رقم ضريبي بصيغة غير صحيحة + لا يوجد عقد مطابق |

### الشاشات الأجدر بالمراجعة

- **مراجعة الاستخراج** — هل تطابق آلية المراجعة البشرية طريقة عمل المحاسبين فعلياً؟
- **تبويب الملاحظات** في أي فاتورة مُعلَّمة — هل أسباب المعالجة المتاحة هي الصحيحة؟
- **الكميات التراكمية** في تبويب البنود — هل هذه هي الطريقة المتبعة لتتبع الكميات المفوترة؟
